How I build agents

For engineering leads who want the detail: the process behind the agents I build, and one of them step by step.

  1. Find the manual workI talk to the people doing it and read the code around it, so the agent solves the real problem, not a demo version.
  2. Small tools, clear rulesThe model reads messy input. MCP tools act on it, and plain code makes the business decision, so every outcome can be audited.
  3. Test in a sandbox, then measureAgent changes run against edge cases before customers see them, and I check the numbers after launch.
