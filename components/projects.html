Trippie — AI Pre-Trip Assistant & MCP Architecture AI Agent

Model Context Protocol (MCP) · Next.js · Node.js · Test Arena Simulation

The Problem

Trippie is the customer-facing AI assistant for travelers pre-trip. When users asked complex questions requiring human escalation, tool calls frequently failed or timed out due to rigid function calling schemas. Furthermore, operators had no staging environment to test agent prompt changes safely.

⚠ Hardest part: Migrating live tool schemas without disrupting active customer conversations

What Shipped

Shipped two major releases in under one week: a sandboxed Test Arena enabling Trip Custodians to simulate edge-case prompts, and a migration to Model Context Protocol (MCP) for modular tool wiring, drastically reducing escalation failures and speeding up latency.
