Every team has a missing piece someone fills by hand.
I build the agent that fills it.

  1. True Tracking

    The system around the code decides whether it holds up.

    I got into engineering because I liked making things work. My first job was mostly about what happens to a backend under real load: slow queries, gaps in authentication and encryption, a system that needed room to grow.

    Fixing those taught me that the code is only part of it.

  2. PickYourTrail

    Find what a team still does by hand, and build the thing that does it for them.

    I started on a legacy PHP codebase that was slowing everyone down and moved core systems to modern Laravel.

    Then I moved five departments off spreadsheets and old tools onto one platform, with zero downtime. Everything since has followed the same rule.

  3. AI agents

    What matters is whether the team's day changed, not how the demo looks.

    Post call logging was eating CX and Sales time, so I built an agent that summarises every call and moves the CRM pipeline on its own. Follow ups and lead qualification became voice agents.

    For Trippie I moved agent tool calls to MCP and built a sandbox where operators test agent behaviour before customers see it. Both launches shipped in under a week.

  4. Vortex

    Releases should be boring.

    Opening pull requests, chasing merge conflicts, cutting releases and hotfixes across our GitHub repositories was all manual. So I built a tool that does it and posts to Slack, with an MCP endpoint so agents can drive releases too.

    It's tested at three levels, down to a browser suite that runs the whole release flow.

  5. How I work

    Rookie of the Year, and top contributor across Plato and Locker Room.

    When a codebase is unfamiliar, I don't say so. I ask for time to understand it, then fix or build what's needed.

    I test past the happy path, keep critical business logic under Pest tests, and I've added UI animations to an internal tool because the people using it all day deserve something pleasant. 10+ modules and 50+ features shipped.
