If your team does something by hand every day,
I'll build an agent that does it for them.

I got into engineering because I liked making things work. My first job, at True Tracking, was mostly about what happens to a backend under real load: slow queries, gaps in authentication and encryption, a system that needed room to grow. Fixing those taught me that the code is only part of it. The system around the code decides whether it holds up.

At PickYourTrail the work turned inward. I started on a legacy PHP codebase that was slowing everyone down and moved core systems to modern Laravel. Then came Plato, the CRM that CX, Sales, Product, Visa and Finance run on every day, with five departments moved off spreadsheets and old tools with zero downtime. After that: the chat platform those teams use to talk with customers, a lead allocation engine that decides which agent gets each new customer, a Visa dashboard, and an HR platform that replaced a paper process. Each one replaced something a team was doing by hand.

AI agents are the same habit with a new tool. Post call logging was eating CX and Sales time, so I built an agent that summarises every call and moves the CRM pipeline on its own. Follow ups and lead qualification became voice agents. For Trippie I moved agent tool calls to MCP and built a sandbox where operators test agent behaviour before customers see it, and both launches shipped in under a week. What matters to me is whether the team's day actually changed, not how the demo looks.

Vortex came from release work. Opening pull requests, chasing merge conflicts, cutting releases and hotfixes across our GitHub repositories was all manual, so I built a tool that does it and posts to Slack, with an MCP endpoint so agents can drive releases too. It's tested at three levels, down to a browser suite that runs the whole release flow. Releases should be boring.

When a codebase is unfamiliar, I don't say so. I ask for time to understand it, then fix or build what's needed. I test past the happy path, keep critical business logic under Pest tests, and I've added UI animations to an internal tool because the people using it all day deserve something pleasant. That's how I ended up Rookie of the Year and the top contributor across Plato and Locker Room, with 10+ modules and 50+ features shipped.
